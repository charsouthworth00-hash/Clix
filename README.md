# Clix 🖱️

Clix is a Linux cursor theme and package created by CJS Studios.

## Install

```bash
sudo apt install ./clix_1.0.1_all.deb
```

Then:

```bash
clix apply
```

## Theme

Clix-OpenAI is an OpenAI-inspired cursor theme for the CJS Studios project.

Clix is an independent CJS Studios project and is not an official OpenAI product.
